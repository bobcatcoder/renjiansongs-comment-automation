RenjianSongs Comment Automation

这是“人间有首歌”频道所有者自用的低频 YouTube 评论辅助工具，不向公众提供账号或服务。

用途

工具通过 YouTube Data API 确认已授权频道、核查公开视频及评论状态，并在满足人工设定的内容质量、频率和重复检查规则后，以该频道身份发布少量原创评论。

运行边界

  • 仅由频道所有者本人授权和使用。
  • 每天最多发布两条评论，且两次发布至少间隔两小时。
  • 不批量评论，不发布链接，不邀请订阅，不进行点赞或订阅操作。
  • 不出售、共享或用于广告定位任何 Google 用户数据。

查看隐私政策

本工具使用 YouTube API Services，并遵守 Google API Services User Data Policy。
