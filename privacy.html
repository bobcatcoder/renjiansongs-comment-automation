隐私政策

最后更新：2026 年 10 月 1 日

RenjianSongs Comment Automation 是“人间有首歌”频道所有者自用的本地工具。本政策说明工具如何访问、使用、存储和保护 Google 用户数据。

访问的数据

在频道所有者通过 Google OAuth 明确授权后，工具可能访问已授权 YouTube 频道的频道标识、公开视频元数据、公开视频评论，以及发布顶层评论所需的权限。

数据用途

数据仅用于验证授权频道、检查候选视频是否公开和适合评论、避免重复评论、发布经规则筛选的少量评论，以及核对评论是否成功显示。数据不会用于广告、画像、信用评估或与本工具无关的用途。

本地存储

OAuth 凭据、发布记录和运行状态仅保存在频道所有者控制的本地设备上，并限制文件访问权限。工具不会建立面向第三方的用户数据库。

共享与出售

本工具不出售 Google 用户数据，不与第三方共享 Google 用户数据，也不允许人工读取与工具功能无关的数据。除 YouTube API Services 为完成授权操作所必需的处理外，不会转移 Google 用户数据。

保留与删除

本地 OAuth 凭据会保留到频道所有者撤销授权或删除凭据为止。运行记录仅为防止重复发布和审计自动化行为而保留，频道所有者可以随时删除这些本地文件。

撤销访问

频道所有者可以在 Google 账号的第三方连接页面随时撤销访问。撤销后，工具将无法再访问频道或发布评论。

Google API 政策

本工具对 Google 用户数据的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求，并同时遵守 YouTube 服务条款。
